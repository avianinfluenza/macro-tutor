# Tutor-T 자동 다음 영상 재생

1. Chrome 또는 Edge에 [Tampermonkey](https://www.tampermonkey.net/)를 설치합니다.
2. [tutor-t-auto-next.user.js](./tutor-t-auto-next.user.js)를 엽니다.
3. **Raw** 버튼을 클릭합니다.
4. Tampermonkey 설치 화면에서 **설치**를 클릭합니다.
5. Tutor-T에 로그인하고 강의 페이지를 엽니다.
6. 첫 영상을 직접 재생합니다.

영상이 끝나면 다음 영상으로 자동 이동하여 재생합니다.

## Update 내용

- AI 튜터 질문이 나타나면 **건너뛰기**를 자동으로 누릅니다.
- 보충 영상 안내가 나타나면 **보충 영상 시청**을 자동으로 누릅니다.
- 재생 중인 강의 또는 보충 영상이 멈추면 자동으로 재생을 다시 시도합니다.
